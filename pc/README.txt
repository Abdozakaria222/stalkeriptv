Stalker TV - نسخة الكمبيوتر (نفس تطبيق التلفزيون بنفس المميزات)
==============================================================

التشغيل
  ويندوز : دبل كليك على Start-StalkerTV.bat      (يحتاج Python 3 مثبّت)
  لينكس/ماك : ./start.sh
  يفتح التطبيق في تبويب جديد في المتصفح الافتراضي (http://127.0.0.1:8765). سيب نافذة الكونسول مفتوحة.
  لإغلاق البرنامج اقفل التبويب (يقفل السيرفر بعد دقيقتين) أو اقفل نافذة الكونسول.
  حساباتك بتتحفظ في المتصفح نفسه، فافتحه دايماً من نفس المتصفح.
  اختياري: التشغيل كنافذة مستقلة بدون شريط المتصفح: python StalkerTV.py --app

تشغيل القنوات والأفلام بكل الصيغ (موصى به)
  أول تشغيل على ويندوز بيسألك "Download it now? [Y/n]" اضغط Y وهو ينزّل ffmpeg لوحده (مرة واحدة).
  لو عايز تنزّله بنفسك أو فشل التحميل:
  حمّل ffmpeg (نسخة essentials) من https://www.gyan.dev/ffmpeg/builds/
  وانسخ الملفين ffmpeg.exe و ffprobe.exe إلى مجلد "ffmpeg" بجانب هذا الملف.
  بدونهما: يشتغل أي ملف mp4 / webm فقط، والبث المباشر (HLS / TS) لن يعمل.
  بالفيديو يتم نسخ الصورة كما هي بدون إعادة ترميز، والصوت يتحول AAC عند الحاجة.

محرك التشغيل: VLC أو ffmpeg (الإعدادات ← محرك التشغيل)
  VLC (الافتراضي): VLC مدمج مع البرنامج نفسه (فولدر vlc جنب StalkerTV.exe)، مش محتاج تثبّت حاجة.
     الصورة بتظهر جوه نافذة التطبيق نفسها، والريموت/الكيبورد شغالين زي ما هما (القائمة، المعلومات، التقديم، القناة اللي بعدها).
     الترجمة اللي جوه الملف بيرسمها VLC بنفسه بدون تأخير (العربي أولاً لو موجود). اختيار الترجمة والصوت من القائمة (الزر الأصفر / Y).
     G / H = تقديم / تأخير الترجمة ربع ثانية.
  ffmpeg: المشغل القديم داخل التطبيق، وهو اللي بيدعم ترجمة الترجمة لأي لغة. G / H = تقديم / تأخير الترجمة نص ثانية.
  VLC (نافذة منفصلة): نفس VLC بس في نافذة ملء الشاشة لوحدها (لو VLC جوه النافذة مش ظاهر عندك). Esc = رجوع.

ترجمة من الإنترنت (OpenSubtitles)
  للأفلام والحلقات اللي ملهاش ترجمة: الإعدادات ← الترجمة ← ترجمة من الإنترنت، واكتب مفتاح API المجاني
  (سجّل في opensubtitles.com ← API Consumers ← New Consumer). حساب مجاني اختياري يخلي التحميلات 20 في اليوم بدل 5.
  من القائمة (Y) أثناء الفيلم: "دوّر على ترجمة من الإنترنت" واختار. العربي بيظهر زي ما هو، والإنجليزي بيتترجم.
  مع VLC جوه النافذة السطر بيترسم بـ VLC نفسه، ومع ffmpeg بيترسم فوق الصورة. الترجمة اللي تختارها بتتحفظ للفيلم ده.
  الشاشة الرئيسية بتعرض تاريخ انتهاء الاشتراك والأيام الباقية، والقائمة فيها "معلومات البث" (الدقة، الكوديك، السرعة...).

الأزرار على الكيبورد
  الأسهم / Enter = تنقل واختيار      Esc أو Backspace = رجوع
  R G Y B أو F1 F2 F3 F4 = الأزرار الملونة (أحمر مفضلة / أصفر القائمة)
  I = معلومات      PageUp / PageDown = تغيير القناة      0-9 = رقم القناة
  Space أو P = تشغيل/إيقاف      F أو F11 = ملء الشاشة

ملاحظات
  - حساباتك وإعداداتك تتحفظ داخل مجلد profile بجانب البرنامج.
  - الاتصال بالسيرفرات يتم عبر السيرفر المحلي (127.0.0.1:8765) فلا يلزم أي Relay.

ملف exe واحد
  شغّل Build-EXE.bat مرة واحدة (يحتاج Python وإنترنت) فيطلع StalkerTV.exe في نفس المجلد.
  بعدها استخدم StalkerTV.exe بدل Start-StalkerTV.bat، وخلّي مجلد ffmpeg بجانبه.

Keys: F11 = full screen, A = change picture fit (auto / stretch / zoom / 16:9 / 4:3 / 21:9). Same choice is in Settings and in the player menu.
